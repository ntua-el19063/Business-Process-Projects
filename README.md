# Projects for Decision Systems course for NTUA

## Business Model Canvas
This assignment focuses on analyzing the business model of Olympia Odos S.A. using the Business Model Canvas framework. It includes:
 - Α presentation of the company’s current business model
 - Τhe development of a hypothetical scenario involving the introduction of a hybrid tolling system (positive change) and severe weather conditions (negative change) 
 - Τhe creation of an adapted business model that responds to these changes.
 
This project combines structured analysis, strategic thinking, and model redesign to demonstrate understanding of business model dynamics.
